Reorder Analysis — Redesign Mockups

Six interactive surfaces for Echelon's Procurement suite: a SKU-driven reorder cockpit with category/product-line rollups and a step-by-step math drawer, growth adjustments and category demand events, a five-stage automation ladder to full autopilot, run reports with an email digest, the complete RFQ lifecycle, and planning policy.

Design handoff · Jul 26, 2026 · sample data generated with the real engine formulas · see REORDER-ANALYSIS-DESIGN-SPEC.md
1

Reorder Analysis (cockpit)

Grouped SKU table with rollups, status KPIs, and the "Explain" drawer that walks every number from demand windows to the suggested order.

 2

Forecast Adjustments

Growth adjustments (% lifts by scope and date range), demand events including category-level allocation, and a before/after impact preview.

 3

Automation Control Center

The five-stage ladder per vendor, category caps, anomaly guardrails, kill switch, and the gate audit log.

 4

Run Report

What last night's run analyzed, drafted, held, and warned about — plus run history and the email digest preview.

 5

RFQ Workbench

Send RFQs, capture vendor quotes, compare landed costs side by side, award (with splits), and convert to POs.

 6

Planning Policy

Exclusion rules with live impact preview, per-product exclusions, and the forecast policy with cohort-reset warning.
How to read these: every number is computed from one shared dataset using the same formulas as the production recommendation engine (blend weights, reorder points, MOQ rounding, 90-day event horizon), so the pages agree with each other. Buttons that would mutate data show a toast describing what they would do.
